DX Cartridge Sender

For the DX machine of Model-TG Plaits Edition.

How it works

  1. Connect the Cycles over USB and open this page in Chrome or Edge (Web MIDI with SysEx). Allow MIDI access when asked.
  2. Choose the Cycles' MIDI port and drop DX7 .syx files: 32-voice cartridges, single voices, or bare 4096-byte banks.
  3. Press Send. The Cycles saves each one in its /DX7/ folder, named after its first voice.
  4. On the Cycles, select a DX track, press FUNCTION + PRESET, open DX7 and choose a cartridge. Contour picks its voices; the pattern keeps it.

    Or: through Elektron Transfer (experimental)

    Transfer only sends audio. Save for Transfer wraps each cartridge in a 48 kHz mono WAV whose samples are the cartridge's bytes. Upload it with Transfer in SMP mode (Device Config > Transfer: SMP), then load it on a DX track with FUNCTION + PRESET as above: the DX machine finds the cartridge inside. Don't play these files on a Sampler track: they are loud noise.

    Only the DX7 dumps in each file are sent (F0 43 … F7), one every two seconds so the Cycles has saved the last one. Nothing is sent anywhere but your MIDI port.
