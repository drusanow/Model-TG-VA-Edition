Hold A + B = hold A, press B. Model-TG's pages open with SETTINGS held; tapping SETTINGS alone still opens the Config Menu. Every knob on every new machine p-locks, slides, takes LFOs and is saved.

DX machine 13: 6-operator FM after the DX7

KnobWhat it does
Color: BRIGBrighter / darker (modulators up to ±12 dB, same loudness)
Shape: TIMEAll the voice's envelopes shorter / longer
Sweep: FDBKLess / more feedback (0 none, 127 most)
Contour: VOICThe voice: 1-63 built in, or 1-32 of your cartridge; its name is shown
SETTINGS + ShapeAlgorithm: VCE (the voice's own), A1-A32

The macros start in the middle (0 = the voice exactly as saved). Picking a voice resets the macros and sets the algorithm back to VCE.

Built-in bank (63 voices): 1-32 Legowelt's "Magic DX7", 33-52 a DX9 cartridge, 53-63 our own: INIT, E.PIANO, SYN BASS, GLASS BELL, BRASS, DRAWBARS, FM PLUCK, SOFT PAD, MARIMBA, CLAV, SINE BASS.

Your own DX7 cartridges:

  • Send a DX7 .syx over USB or MIDI IN (the DX Cartridge Sender page, a SysEx librarian or Dexed). It is saved in /DX7/.
  • On a DX track: FUNCTION + PRESET › DX7 › pick it ("Cartridge loaded").
  • The pattern keeps it and reloads it with the project.

Turn Decay up: a low Decay cuts pads short.

LFO 2, 3 and 4, and LFOs to MIDI CC

MIDI CC row: DATA, turn, DATAThe CC that LFO sends (OFF / 0-127), on the track's MIDI channel; switched on at the second press

Trig generator

SETTINGS + TRACK: RND (chance DNS %) or EUC (HIT trigs, ROT rotation). Options: NOT random notes from SCL / KEY / OCT / RNG, VEL random velocity VMN-VMX. Select GEN and press DATA (again for another result). It replaces the track's trigs; there is no undo.

Quantised mute and solo

While playing, mutes change on the next bar. SETTINGS + pad solos that track (same again = SOLO OFF). Device Config › Mute Q: 1BAR / PTN / OFF.

Alternative send effects

SETTINGS + PAGE › turn DATA, saved per pattern.

  • Delay: DELAY, PING (ping-pong), TAPE, CHORUS (flanger past half Feedback)
  • Reverb: REVERB, PHASER, SPRING, RING, DIST, RESO (Size = pitch, Tone = ring)

The FX page's Time / Feedback / Size / Tone knobs drive the chosen effect.

Slide trigs and Scale Lock

SETTINGS + trig key: slide trig on/off (double-blinks). Every value that differs glides into the slide trig.

FUNC + PAGE: Scale menu: Scl and Key; played notes snap to the scale.
